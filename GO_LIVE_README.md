# Britium Express Go-Live Package

This package contains the latest build-ready source and production build artifacts.

## Included
- src/
- api/
- supabase/
- public/
- dist/
- Vite and TypeScript config files
- vercel.json
- index.html
- GO_LIVE_MANIFEST.txt

## Notes
- node_modules is intentionally excluded
- dist/ is included in the deployable bundle
- use npm install before local rebuild
